## Taller2_P.O.O
10. Preguntas de comprensión
Responde brevemente y con tus propias palabras. Hacen parte de los entregables.
1.  ¿Qué ventaja tiene dibujar el diagrama UML antes de escribir el código?
2.  ¿A qué parte del código corresponde cada una de las tres divisiones del diagrama de clases?
3.  ¿Cuál es la diferencia entre un comentario // y un bloque /** ... */ de Javadoc?
4.  ¿Por qué es importante documentar el código en un equipo de trabajo?


Respuestas

 1.Permite organizar y visualizar la estructura del programa antes de programarlo, facilitando y evitando errores.

2.
*La primera división corresponde al nombre de la clase.
*La segunda corresponde a los atributos o variables.
*La tercera corresponde a los métodos o funciones.

 3.El comentario // sirve para escribir una explicación breve dentro del código y no genera documentación. El bloque /** ... */ se usa para documentar clases y métodos y puede ser procesado por Javadoc para generar documentación.

4.Porque ayuda a que los demás integrantes entiendan cómo funciona el código, puedan modificarlo o corregirlo y trabajen de manera más organizada.
